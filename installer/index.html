Гайд в директ — установка

Человек пишет под вашим постом «+» или кодовое слово → ему приходит сообщение в директ, а под комментарием — ответ. Всё ставится с этой страницы, терминал не нужен. Страница работает только на вашем компьютере: секреты отсюда уходят только в Meta и в ваш Cloudflare.

0Подготовка в Instagram (на телефоне, один раз)

Робот работает только с профессиональным Instagram, привязанным к странице Facebook. Так требует Meta.

а) Профессиональный аккаунт

  1. Instagram → ваш профиль → Edit profile (Редактировать профиль).
  2. Если внизу есть синяя строка Switch to professional account — нажмите, выберите любую категорию, тип Creator. Если строки нет — аккаунт уже профессиональный.

б) Страница Facebook

  1. Там же, в Edit profile, в блоке «Profile information» строка Facebook → Connect.
  2. Войдите в тот же Facebook, через который будете заходить в кабинет Meta на компьютере.
  3. Если страницы нет — Create a Facebook Page, любое название → Done. В строке «Facebook» должно появиться имя страницы.

Аккаунт должен быть публичным — у профессиональных аккаунтов так по умолчанию.

Робот живёт бесплатно на Cloudflare, в вашем аккаунте.

2Приложение Meta (на компьютере, один раз)

Это «разрешение» от Meta, через которое робот читает комментарии и пишет в директ.

  1. Откройте developers.facebook.com/apps/creation (войдите тем же Facebook, что в шаге 0).
  2. Название — любое, но без слов «IG», «Insta», «Facebook» (Meta их не пропустит). Почта уже подставлена → Далее.
  3. Слева в фильтре выберите Другое, прокрутите вниз до «Ищете что-то другое?» → отметьте Другое → Далее.
  4. Тип приложения — Компания → Далее → Создание приложения. Meta попросит пароль от Facebook.
  5. Откроется «Доступные продукты». Напротив Instagram нажмите Настроить.

Вверху страницы приложения будет «ID приложения: 1234…» — он понадобится в шаге 3.

3Токен и секрет

а) Токен (Graph API Explorer)

  1. Откройте Graph API Explorer.
  2. Справа Приложение Meta → выберите своё приложение.
  3. Добавить разрешение → раздел Other → отметьте instagram_basic, instagram_manage_comments, instagram_manage_messages.
  4. Там же раздел Events Groups Pages → отметьте pages_show_list, pages_read_engagement, pages_manage_metadata, business_management. Должно стать «Выбранные варианты: 7».
  5. Нажмите синюю Generate Access Token. В окне Facebook — Изменить настройки (если есть), затем на всех экранах (Страницы, Компании, Аккаунты Instagram) Продолжить, в конце Сохранить.

    5Последние шаги

    а) Войдите в админку

    Откройте ссылку. При первом входе придумайте email и пароль (от 12 символов) — восстановления нет, сохраните их. Сделайте это сразу.

    б) Разрешите доступ к сообщениям в Instagram (обязательно)

    Без этого Meta не даст роботу писать в директ (ошибка «disabled access to Instagram Direct»).

    1. Instagram → профиль → ☰ → Settings and activity.
    2. Раздел «How others can interact with you» → Messages and story replies.
    3. Message requests → блок «Connected tools» → включите Allow access to messages.

    в) Опубликуйте приложение Meta

    Пока приложение «в разработке», Meta не присылает комментарии посторонних людей.

    1. Кабинет Meta → ваше приложение → Настройки приложения → Основное.
    2. URL Политики конфиденциальности:
    3. Удаление данных пользователей → «URL инструкций для удаления данных» → та же ссылка.
    4. Категория → Бизнес и Страницы → внизу Сохранить изменения.
    5. Вверху страницы переключатель Режим приложения: «режим разработки» → рабочий режим.

    г) Создайте правило

    1. Опубликуйте пост в Instagram (если ещё нет).
    2. Админка → Обновить список постов → выберите пост → Новое правило.
    3. Ключевые слова: + и/или ваше слово (например, гайд). Для «+» обязательно режим точно совпадает с одним из слов, иначе сработает на любой комментарий с плюсом.
    4. Текст сообщения в директ (ссылка на гайд) и ответ под комментарием → сохранить и включить.

    д) Проверка

    С другого аккаунта (свои комментарии робот пропускает) напишите ключевое слово под постом. Через несколько секунд придёт сообщение в директ — если тот аккаунт не подписан на вас, ищите в папке «Запросы». Потом появится ответ под комментарием.
