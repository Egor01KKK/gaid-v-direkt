# Гайд в директ

Человек пишет под вашим постом в Instagram «+» или кодовое слово → ему приходит сообщение в директ (например, со ссылкой на гайд), а под комментарием появляется ответ «Отправил в директ».

- **Свой робот, без подписок.** Работает в вашем бесплатном аккаунте Cloudflare, через ваше приложение Meta. Сторонние сервисы не видят ваши сообщения и токены.
- **Сначала DM, потом ответ.** Если сообщение не ушло, робот не напишет под комментарием, что оно отправлено.
- **«+» и русские слова.** Режим «точно совпадает» для «+», «содержит» для фраз вроде «пришли гайд».
- **Без дублей.** Повторные уведомления от Meta не дают второго сообщения.
- **Админка на русском.** Правила, посты, журнал срабатываний, аварийная остановка.

## Что понадобится

- Instagram **профессиональный** (Автор или Бизнес), **публичный**, привязанный к **странице Facebook**. Как это сделать — в мастере установки, шаг 0.
- Аккаунт Facebook, через который управляется эта страница.
- Компьютер с macOS или Windows и интернет. Node.js ставить не нужно — установщик скачает его сам.
- Бесплатные аккаунты Cloudflare и Meta for Developers (заводятся по ходу установки).

## Установка

1. Скачайте программу: зелёная кнопка **Code → Download ZIP** на GitHub, распакуйте.
2. Запустите установщик:
   - **macOS:** двойной клик по **«Установить.command»**. Если macOS скажет, что не может проверить разработчика, — правый клик по файлу → **Открыть** → **Открыть**.
   - **Windows:** двойной клик по **«Установить.bat»** *(версия для Windows пока не проверялась на реальном компьютере)*.
3. Откроется страница мастера в браузере. Дальше — по шагам на ней, всё на русском.

Установщик ничего не ставит в систему и не просит пароль администратора: Node.js и компоненты лежат внутри папки программы (`.runtime`, `node_modules`). Удалить всё — удалить папку.

Повторный запуск безопасен: можно поставить заново или обновить токен — вход в админку сохранится.

## Если что-то пошло не так

| Что видите | Что сделать |
|---|---|
| В мастере: «Ни к одной из ваших страниц Facebook не привязан профессиональный Instagram» или «у этого аккаунта Facebook нет ни одной страницы» | Шаг 0 мастера: переключите Instagram на профессиональный и в **Edit profile → Facebook → Connect** создайте/выберите страницу. Facebook должен быть тот же, что в кабинете Meta. Затем заново **Generate Access Token** в Explorer. |
| В окне Facebook при выдаче токена нечего выбрать | Та же причина: у этого Facebook нет страницы. См. строку выше. |
| «У аккаунта Cloudflare ещё нет адреса на workers.dev» | Откройте ссылку из сообщения, Cloudflare сам выдаст адрес. Вернитесь и нажмите «Установить» ещё раз. |
| В админке/журнале: «The account owner has disabled access to Instagram Direct Messaging» | Instagram → ☰ → **Settings and activity → Messages and story replies → Message requests → Connected tools → Allow access to messages** — включить. |
| Комментарии посторонних людей не доходят | Приложение Meta должно быть в **рабочем режиме** (шаг 5в мастера). |
| Сообщение не видно в директе у того, кто комментировал | Если он не подписан на вас — оно в папке **«Запросы»**. |
| «+» срабатывает на любой комментарий с плюсом | В правиле выберите режим **«точно совпадает с одним из слов»**. |
| Свой комментарий не срабатывает | Так и задумано — проверяйте с другого аккаунта. |

## Ограничения Meta

- Одно сообщение в директ на один комментарий, в течение 7 дней после комментария.
- Работает через **Instagram API со входом через Facebook**: нужен профессиональный Instagram, привязанный к странице Facebook.
- Робот обслуживает **ваш** аккаунт. Сделать из него сервис для чужих аккаунтов (как ManyChat) — это отдельная история: Meta потребует проверку бизнеса и проверку приложения (App Review).

## Для разработчиков

Cloudflare Workers + Hono + D1 (Drizzle) + Queues + Cron, админка — React (Vite).

```bash
npm ci --ignore-scripts && npm ci --ignore-scripts --prefix admin
npm rebuild better-sqlite3   # только для тестов
npm test && npm run lint && npm run typecheck
```

Мастер установки — `installer/` (локальный сервер на 127.0.0.1, секреты передаются в wrangler через stdin и не пишутся на диск). Вход через Facebook включается секретом `META_BASE_URL=https://graph.facebook.com`.
