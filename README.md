# Гайд в директ

Человек пишет под вашим постом в Instagram «+» или кодовое слово → ему приходит сообщение в директ (например, со ссылкой на гайд), а под комментарием появляется ответ «Отправил в директ».

Робот работает в вашем бесплатном аккаунте Cloudflare и через ваше приложение Meta. Подписок нет, чужие сервисы ваши сообщения не видят.

---

# Установка — пошагово

**Сколько времени:** около 40 минут. Первые 10 — на телефоне, остальное — на компьютере.

**Что нужно:**

- Телефон с Instagram, который вы хотите подключить.
- Аккаунт Facebook. Подойдёт личный: через него будете управлять страницей.
- Если вы в России — VPN на компьютере: без него сайты Facebook и Meta не откроются.

Делайте шаги по порядку и не пропускайте. Если что-то выглядит не так, как здесь написано, загляните в раздел [«Если что-то пошло не так»](#если-что-то-пошло-не-так) в конце.

---

## Шаг 1. Instagram: профессиональный аккаунт (на телефоне)

Meta разрешает роботам писать в директ только профессиональным аккаунтам.

1. Откройте Instagram и перейдите в свой профиль.
2. Нажмите **Edit profile** (по-русски — «Редактировать профиль»).
3. Если внизу есть синяя надпись **Switch to professional account**, нажмите её. Категорию выберите любую, тип — **Creator**.
   Если такой надписи нет, аккаунт уже профессиональный. Переходите дальше.

Аккаунт должен быть **публичным**. У профессиональных аккаунтов так по умолчанию.

## Шаг 2. Instagram: привязать страницу Facebook (на телефоне)

Без страницы Facebook ничего не заработает. Это самая частая причина, почему люди застревают.

1. В том же **Edit profile** найдите блок «Profile information» и строку **Facebook** → нажмите **Connect**.
2. Войдите в Facebook. Запомните, в какой именно: в шаге 5 на компьютере нужно войти **в этот же** Facebook.
3. Если страницы у вас нет, нажмите **Create a Facebook Page**. Название любое, например ваше имя → **Done**.
4. Проверьте: в строке **Facebook** теперь стоит название страницы.

## Шаг 3. Скачать программу (на компьютере)

1. Откройте https://github.com/Egor01KKK/gaid-v-direkt и нажмите зелёную кнопку **Code** → **Download ZIP**.
   Если вам прислали архив файлом, просто скачайте его.
2. Откройте папку **Загрузки** и дважды щёлкните по архиву. Рядом появится папка с программой.
3. Перетащите эту папку куда удобно, например на **Рабочий стол**.
   Не удаляйте её после установки: через неё робот обновляется и переустанавливается.

## Шаг 4. Запустить установщик

1. Откройте папку программы и дважды щёлкните по файлу **Установить.command**.
2. **В первый раз macOS его заблокирует.** Появится окно о том, что Apple не может проверить файл. Нажмите **Готово**: в корзину не перемещайте. Так macOS поступает со всеми программами из интернета, которые не куплены в App Store. Файл безопасен: он ничего не ставит в систему и не просит пароль администратора.
3. Откройте меню  (яблоко в левом верхнем углу) → **Системные настройки** → слева **Конфиденциальность и безопасность**.
4. Прокрутите правую часть вниз до раздела **Безопасность**. Там будет строка про «Установить.command» и кнопка **Всё равно открыть** (или **Открыть**). Нажмите её.
   Кнопка видна около часа после попытки открыть файл. Если её нет, снова дважды щёлкните по «Установить.command» и вернитесь сюда.
5. Подтвердите ещё раз в появившемся окне и введите пароль от Mac (или приложите палец).
6. Откроется чёрное окно **Терминала** с текстом. Ничего в нём печатать не нужно: оно работает само.
   - В первый раз установщик 2–3 минуты скачивает нужные компоненты. Подождите.
   - Потом сам откроется браузер со страницей **«Гайд в директ — установка»**. Это мастер, дальше всё делается в нём.
   - **Не закрывайте окно Терминала**, пока не закончите. Если закрыть, мастер перестанет работать. Тогда снова дважды щёлкните «Установить.command».

Запускать установщик второй раз можно спокойно: блокировки уже не будет.

## Шаг 5. Мастер: войти в Cloudflare

Cloudflare — это место, где бесплатно живёт ваш робот.

1. В мастере, в разделе **1. Вход в Cloudflare**, нажмите **Войти в Cloudflare**.
2. Откроется сайт Cloudflare. Если аккаунта нет, зарегистрируйтесь (**Sign up**): это бесплатно, банковская карта не нужна. Подтвердите почту по письму от Cloudflare.
3. На странице с запросом доступа нажмите **Allow**.
4. Вернитесь во вкладку мастера. В разделе 1 должно появиться, что вход выполнен.

## Шаг 6. Мастер: создать приложение Meta

Приложение Meta — это разрешение, через которое робот читает комментарии и пишет в директ. Создаётся один раз.

1. В разделе **2** мастера нажмите ссылку **developers.facebook.com/apps/creation**.
2. Войдите в **тот же Facebook, что в шаге 2**.
   Если Meta предложит сначала зарегистрироваться как разработчик, согласитесь и пройдите регистрацию (подтверждение почты или телефона). Это бесплатно.
3. **Название приложения** — любое, но без слов «IG», «Insta», «Instagram», «Facebook»: Meta такие отклоняет. Например: «Гайд в директ». Почта подставится сама → **Далее**.
4. Слева в фильтре выберите **Другое**. Прокрутите вниз до «Ищете что-то другое?», отметьте **Другое** → **Далее**.
5. Тип приложения — **Компания** → **Далее** → **Создание приложения**. Meta попросит пароль от Facebook.
6. Откроется «Доступные продукты». Напротив **Instagram** нажмите **Настроить**.
7. Вверху страницы приложения написано **ID приложения** и цифры. Скопируйте их.

## Шаг 7. Мастер: ID, токен и секрет

Раздел **3** мастера.

**а) ID приложения**

1. Вставьте цифры из шага 6 в поле **ID приложения**.

**б) Токен**

1. Нажмите ссылку **Откройте Graph API Explorer**. Ваше приложение там уже будет выбрано: справа в поле **Приложение Meta** должно стоять его название. Если там другое, выберите своё.
2. Нажмите **Добавить разрешение** → раздел **Other** → отметьте три пункта:
   `instagram_basic`, `instagram_manage_comments`, `instagram_manage_messages`.
3. Там же откройте раздел **Events Groups Pages** → отметьте четыре пункта:
   `pages_show_list`, `pages_read_engagement`, `pages_manage_metadata`, `business_management`.
   Проверьте, что написано **«Выбранные варианты: 7»**.
4. Нажмите синюю кнопку **Generate Access Token**. Откроется окно Facebook:
   - если есть кнопка **Изменить настройки**, нажмите её;
   - на экранах со страницами, компаниями и аккаунтами Instagram **отметьте свою страницу и свой Instagram** → **Продолжить**;
   - в конце нажмите **Сохранить**.
5. В поле **Маркер доступа** появится длинный текст, начинающийся на «EA». Скопируйте его значком справа от поля и вставьте в мастер, в поле **Токен из Explorer**.

**в) Секрет приложения**

1. Вернитесь в кабинет Meta, в своё приложение. Слева **Настройки приложения** → **Основное**.
2. В строке **Секрет приложения** нажмите **Показать**. Meta может попросить пароль от Facebook.
3. Скопируйте секрет (32 символа) и вставьте в мастер, в поле **Секрет приложения**.

**г) Проверка**

1. Нажмите **Проверить**.
2. Ниже появится ваша страница Facebook и Instagram. Выберите их.
   Если вместо этого появилась ошибка, смотрите [«Если что-то пошло не так»](#если-что-то-пошло-не-так).

## Шаг 8. Мастер: установить робота

1. В разделе **4** нажмите **Установить робота**.
2. Подождите 2–3 минуты. Мастер покажет список шагов, и у каждого должна появиться галочка.
   - Если появилась надпись, что у аккаунта Cloudflare нет адреса на workers.dev, откройте ссылку из сообщения. Cloudflare выдаст адрес сам. Вернитесь в мастер и снова нажмите **Установить робота**.
   - Жёлтое предупреждение — не страшно. Сделайте, что в нём написано, и продолжайте.
3. Когда всё готово, появится раздел **5. Последние шаги** со ссылкой на вашу админку.

## Шаг 9. Админка: создать вход

1. В разделе 5 нажмите **Копировать** у ссылки на админку и откройте её в новой вкладке.
2. Откроется «Создайте аккаунт». Придумайте email и пароль: не короче 12 символов.
3. Нажмите **Создать аккаунт и войти**.
   **Запишите email и пароль.** Восстановить пароль нельзя.

Делайте это сразу после установки: кто первым откроет ссылку, тот и создаст вход.

## Шаг 10. Instagram: разрешить доступ к сообщениям (на телефоне)

Без этого Meta не даст роботу писать в директ, даже если всё остальное готово.

1. Instagram → профиль → ☰ (три полоски справа вверху) → **Settings and activity**.
2. Раздел «How others can interact with you» → **Messages and story replies**.
3. **Message requests** → в блоке **Connected tools** включите **Allow access to messages**.

Если Instagram у вас на русском, пункты называются так же по смыслу: «Настройки и действия» → «Сообщения и ответы на истории» → «Запросы на переписку» → «Подключённые инструменты».

## Шаг 11. Опубликовать приложение Meta (на компьютере)

Пока приложение «в разработке», Meta не присылает роботу комментарии посторонних людей. Работать будут только ваши.

1. Кабинет Meta → ваше приложение → слева **Настройки приложения** → **Основное**.
2. **URL Политики конфиденциальности** мастер вписал сам. Проверьте, что там стоит ссылка, которая кончается на `/privacy`. Если поле пустое, возьмите ссылку в разделе 5 мастера (кнопка **Копировать**).
3. **Удаление данных пользователей** → «URL инструкций для удаления данных» → вставьте ту же ссылку.
4. **Категория** → **Бизнес и Страницы**.
5. Внизу страницы нажмите **Сохранить изменения**.
6. Вверху страницы переключатель **Режим приложения**: переведите из «режим разработки» в **рабочий режим**.

Проверка приложения Meta (App Review) для своего аккаунта **не нужна**.

## Шаг 12. Создать правило (в админке)

1. Опубликуйте пост в Instagram, если ещё нет.
2. В админке нажмите **↻ Обновить список постов**. Появятся ваши посты.
3. Под нужным постом нажмите **Настроить правило**.
4. **Когда срабатывать:**
   - для «+» выберите **Точно совпадает с одним из слов**. Иначе робот ответит на любой комментарий, где есть плюс;
   - для слов и фраз вроде «гайд» или «пришли гайд» подойдёт **Содержит любое из слов**.
5. **Ключевые слова:** введите слово и нажмите **Enter**. Можно несколько: например, `+` и `гайд`. Большие и маленькие буквы не важны.
6. Включите **Отвечать под комментарием** и напишите ответ, например «Отправил в директ 📩».
7. Включите **Отправлять сообщение в директ автору комментария** и напишите текст со ссылкой на гайд.
   Ссылка в тексте директа не всегда нажимается. Надёжнее включить **Добавить кнопку со ссылкой**.
8. Нажмите **Сохранить**, потом **Включить**.

Чтобы правило работало сразу на всех новых постах, нажмите вверху **+ Новое правило** → **Для всех новых постов**.

## Шаг 13. Проверить

Мастер проверит всю цепочку сам и скажет, где проблема.

1. Вернитесь во вкладку мастера, в самый низ: раздел **6. Проверка: всё ли работает**.
2. Нажмите **Начать проверку**.
3. Мастер покажет ваше правило и попросит написать комментарий. Возьмите **другой** аккаунт Instagram, не тот, что подключали: на свои комментарии робот не отвечает специально.
4. Напишите под постом ключевое слово.
5. Мастер по очереди отметит: комментарий дошёл → правило сработало → сообщение ушло в директ → ответ появился.
   - Если где-то крестик — ниже будет написано, что случилось и что сделать. Исправьте и нажмите **Начать проверку** ещё раз, с новым комментарием.
6. На втором аккаунте проверьте директ. Если второй аккаунт на вас не подписан, сообщение будет в папке **«Запросы»**.

Если мастер уже закрыт — дважды щёлкните «Установить.command», раздел 6 появится сам.

**Готово.** Окно Терминала теперь можно закрыть: робот работает в Cloudflare, компьютер можно выключать.

# Если что-то пошло не так

| Что видите | Что сделать |
|---|---|
| macOS: «Не удалось открыть Установить.command», и в настройках нет кнопки «Всё равно открыть» | Снова дважды щёлкните по файлу, нажмите **Готово** и сразу откройте **Системные настройки → Конфиденциальность и безопасность**. Кнопка видна около часа после попытки. |
| Окно Терминала пишет «✗ Не получилось связаться с nodejs.org» или «Не получилось установить компоненты» | Проверьте интернет (VPN может мешать — попробуйте с ним и без) и снова запустите «Установить.command». |
| Браузер не открылся сам | В окне Терминала есть строка «Мастер открыт в браузере: http://127.0.0.1:…». Скопируйте этот адрес и откройте в браузере. |
| Мастер: «Ни к одной из ваших страниц Facebook не привязан профессиональный Instagram» или «у этого аккаунта Facebook нет ни одной страницы» | Повторите шаги 1–2. Facebook в Instagram и Facebook в кабинете Meta должен быть **один и тот же**. Потом в Explorer снова **Generate Access Token** и в мастере **Проверить**. |
| В окне Facebook при выдаче токена нечего выбрать | Та же причина: у этого Facebook нет страницы. Шаг 2. |
| Мастер: «Это не похоже на токен из Explorer» | Скопировали не то. Токен — в поле **Маркер доступа**, начинается на «EA», очень длинный. Копируйте значком справа от поля. |
| Мастер: «Секрет приложения — 32 символа» | Секрет в **Настройки приложения → Основное → Секрет приложения → Показать**. Не путайте с ID приложения (там только цифры). |
| «У аккаунта Cloudflare ещё нет адреса на workers.dev» | Откройте ссылку из сообщения, Cloudflare выдаст адрес сам. Вернитесь и нажмите «Установить робота» ещё раз. |
| В админке: «The account owner has disabled access to Instagram Direct Messaging» | Шаг 10. |
| Свои комментарии работают, а чужие — нет | Приложение Meta не опубликовано. Шаг 11. |
| Человек говорит, что сообщения нет | Пусть посмотрит в папке **«Запросы»** в директе. |
| «+» срабатывает на любой комментарий с плюсом | В правиле выберите **Точно совпадает с одним из слов**. |
| Свой комментарий не срабатывает | Так задумано. Проверяйте с другого аккаунта. |
| Сбросили секрет приложения в кабинете Meta | Робот перестанет принимать комментарии (в админке будет красная карточка). Запустите «Установить.command», вставьте новый секрет → **Проверить** → **Установить робота**. |
| Проверка: «Комментарий так и не дошёл до робота» | Приложение Meta в рабочем режиме? (шаг 11). Комментарий с другого аккаунта и под постом подключённого аккаунта? |
| Проверка: «не подошёл ни под одно правило» | При режиме **Точно совпадает** комментарий должен состоять только из ключевого слова. |
| Забыли пароль от админки | Восстановления нет. Напишите тому, кто дал вам программу. |

Если вопрос не решился: в папке программы, в `installer/logs`, лежит журнал установки. Секретов в нём нет, его можно переслать тому, кто помогает.

## Как обновить или переустановить

Дважды щёлкните **Установить.command** в той же папке и пройдите мастер ещё раз. Вход в админку и правила сохранятся.

## Ограничения Meta

- Одно сообщение в директ на один комментарий, в течение 7 дней после комментария.
- Нужен профессиональный Instagram, привязанный к странице Facebook.
- Робот обслуживает **ваш** аккаунт. Сделать из него сервис для чужих аккаунтов (как ManyChat) — отдельная история: Meta потребует проверку бизнеса и проверку приложения (App Review).

## Для разработчиков

Cloudflare Workers + Hono + D1 (Drizzle) + Queues + Cron, админка — React (Vite).

```bash
npm ci --ignore-scripts && npm ci --ignore-scripts --prefix admin
npm rebuild better-sqlite3   # только для тестов
npm test && npm run lint && npm run typecheck
```

Мастер установки — `installer/`: локальный сервер на 127.0.0.1. Секреты передаются в wrangler через stdin и не пишутся на диск. Вход через Facebook включается секретом `META_BASE_URL=https://graph.facebook.com`.
